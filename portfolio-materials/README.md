# SmartHealth Nepal 2.0 — Portfolio Materials

This folder contains presentation assets for the SmartHealth Nepal 2.0 project.

```
portfolio-materials/
├─ README.md                      ← this file
├─ project-summary/
│   ├─ SmartHealth_Nepal_Portfolio.md   ← full 16-section portfolio profile
│   └─ Screenshot_Captions.md           ← captions for each screenshot
└─ demo-notes/
    └─ Demo_Accounts_and_Setup.md       ← demo logins, setup & DB notes
```

## Quick facts

- **Stack:** PHP 8.2 · MySQL/MariaDB 10.4 · Apache 2.4 · Bootstrap 5 · vanilla JS
- **Database:** `smarthealth` — 26 tables + 1 view (27 objects), utf8mb4
- **Portals:** Patient app, Hospital portal, Super-admin panel
- **Languages:** English / Nepali (UTF-8)

## Demo entry points

| Portal | URL |
|--------|-----|
| Patient | http://localhost/smarthealth_nepal/ |
| Admin | http://localhost/smarthealth_nepal/admin/ |
